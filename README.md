# Italiano — Webflow Restaurant & Café Template

An exact, 1:1 replica of the **Italiano Webflow Template** (`https://italiano-webflow-template.webflow.io/`), featuring the authentic layout, typography, Webflow interactions, animations, assets, and styling.

---

1. **Brand Navbar**:
   - Iconic Italian crest logo and brand emblem
   - Animated lottie hamburger menu circle
   - Shopping bag cart trigger with counter
   - Clean, top-aligned navigation

2. **Full-Screen Webflow Hero Slider**:
   - 3 Signature slides:
     - **Slide 1**: *Experience* — `Italiano Ristorante` with `hero-image-slide-01`
     - **Slide 2**: *Techniques* — `authentic experience` with `hero-image-slide-02`
     - **Slide 3**: *Authentic* — `Rooted in Tradition` with `hero-image-slide-03`

## 🚀 How to Run Locally

You can launch a local server in PowerShell or Command Prompt:

```powershell
cd d:\cafe-website
python -m http.server 8000
```

Then open **`http://localhost:8000`** in your browser, or double-click **`index.html`** directly.
